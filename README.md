### SYSTEM LOGS // ARCHITECTURE PROFILE

Computer Engineer and graduate researcher building high-reliability distributed systems, declarative infrastructure pipelines, and low-latency inference architectures.

- **OS Internals & Declarative Frameworks:** Linux is the primary execution kernel. Implementation of reproducible systems via [NixOS](https://nixos.org/), kernel process lifecycle optimization, and POSIX compliance.
- **DevOps, Virtualization & Cloud Runtimes:** Automated container orchestration, isolated hypervisor sandbox execution via [VirtualBox](https://www.virtualbox.org/), compute workload provisioning across [Amazon EC2](https://aws.amazon.com/ec2/), and deterministic CI/CD pipelines via [GitHub Actions](https://github.com/features/actions).
- **Concurrency & Parallel Computation:** Multi-core POSIX thread synchronization in C/C++ and massive data-parallel hardware acceleration utilizing [NVIDIA CUDA](https://developer.nvidia.com/cuda-toolkit).
- **Edge Artificial Intelligence & MLOps:** End-to-end decoupled data pipelines featuring [Temporal Fusion Transformers](https://arxiv.org/abs/1912.09363) and [FinBERT](https://huggingface.co/ProsusAI/finbert), on-device edge model execution with [Google ML Kit](https://developers.google.com/ml-kit), and autonomous agent networks based on [Retrieval-Augmented Generation (RAG)](https://www.kaggle.com/).
