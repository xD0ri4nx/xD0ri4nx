### About Me

Computer Engineer and graduate student specializing in systems architecture, declarative infrastructure, and low-latency software development. My workflow prioritizes system reproducibility, minimal runtime overhead, and decoupled service design.

- **Linux and Operating System Internals:** Linux is my primary operating system. Proficient in declarative system configurations using Nix and NixOS, desktop customization, tiling window managers, process lifecycle management, and POSIX compliance.
- **DevOps, Virtualization and Cloud:** Experienced with containerized workflows, virtualized sandboxes using VirtualBox, cloud compute provisioning on AWS EC2, and structured CI/CD automation pipelines.
- **Systems and High-Performance Computing:** Designing concurrent, multithreaded architectures in C and C++, as well as massive parallel computing pipelines using NVIDIA CUDA.
- **Applied Artificial Intelligence and Edge ML:** Architecting decoupled data ingestion pipelines (Temporal Fusion Transformers, FinBERT), running on-device neural models using Google ML Kit, and designing retrieval-augmented generation (RAG) agent systems.
