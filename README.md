================================================================================
PROJECT INDEX // PRODUCTION & RESEARCH BUILDS

* **[AI Trading Co-Pilot](https://github.com/xD0ri4nx/bot_investitiV2.git)**
  * End-to-end multimodal predictive architecture coupling Temporal Fusion Transformers (TFT) with FinBERT embeddings.
  * Employs custom Sharpe Loss objective optimization and an interactive live dashboard for risk-adjusted inferences.
  * Stack: Python, TensorFlow, Keras 3, FinBERT

* **[HeliBoard ML Engine Fork](https://github.com/xD0ri4nx/SmartBoard.git)**
  * Privacy-preserving on-device machine translation engine embedded into an open-source Android keyboard.
  * Decoupled asynchronous tokenization pipeline preventing input lag on the UI thread.
  * Stack: Java, Android SDK, Google ML Kit

* **[Cyberpunk 2020: Netrunner Simulator](https://github.com/xD0ri4nx/Netrunners.js.git)**
  * Roguelite procedural hacking simulation built on deterministic hierarchical state machines.
  * Decoupled architecture using Zustand and XState to isolate state mutation from render lifecycles.
  * Stack: React, TypeScript, Tailwind CSS, Zustand, XState

* **[RSA Decryption Simulation & Benchmarking](https://github.com/xD0ri4nx/RSA-Decryption.git)**
  * High-performance comparative analysis suite measuring RSA decryption throughput in GNU/Linux.
  * Evaluates single-thread sequential C execution against POSIX system threads and massively parallel CUDA GPU kernels.
  * Stack: C, CUDA, POSIX Threads

* **[Fitness Tracker Web Platform](https://github.com/xD0ri4nx/FitnessTracker.git)**
  * Full-stack web application for sports facilities featuring role-based access control and strict SQL data schemas.
  * Stack: C#, .NET 9.0, Relational SQL

* **[ACAT: Computational Automata Tool](https://github.com/xD0ri4nx/acat.git)**
  * Visual educational simulation engine modeling deterministic and non-deterministic finite automata state transitions.
  * Stack: TypeScript, Web Standards
